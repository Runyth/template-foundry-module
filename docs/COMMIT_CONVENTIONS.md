# Commit conventions

Use a Gitmoji followed by a capitalized imperative summary without a scope.
Keep the summary at or below 80 characters.

```text
✨ Feat: Add deterministic source archives
🐛 Fix: Preserve compendium pack identifiers
🔧 Prog: Update the shared repository tooling
```

For non-trivial changes, add a blank line and a body explaining why the change
is necessary. Use conventional footers such as `BREAKING CHANGE:`, issue
references, and `Signed-off-by:` where applicable.
